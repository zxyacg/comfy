# XHS Workflow Nodes — 小红书图文批量生成插件

## 项目概述

XHS Workflow Nodes 是一个 ComfyUI 插件，用于批量生成小红书图文内容。
项目位于 `Amake/zxy_xhs/`，通过 ComfyUI 的 custom_node 机制加载。

**设计理念：**
- 每个节点只做一件事（单一职责）
- 通过节点组合实现复杂工作流
- 支持模板化批量处理
- 低耦合，高内聚

## 代码准入规则

> 以下规则是项目 `配方.md` 中明确的硬性要求，修改代码前必须逐条检查。

| # | 规则 | 说明 |
|---|------|------|
| 1 | 每个文件 ≤ 300 行 | 当前最大文件 `template_engine.py` 211 行 |
| 2 | 新功能优先新增模块 | 禁止为加功能修改多个无关模块 |
| 3 | 不允许顺手重构 | 一个功能一个改动，不混合无关重构 |
| 4 | 修改公共接口需说明影响范围 | 修改前必须标记影响哪些模块 |
| 5 | 前端不能直接访问文件系统 | JS 仅做 UI，不走 Node.js API |
| 6 | 业务模块不能直接依赖 ComfyUI 内部实现 | `lib/` 完全独立于 ComfyUI |
| 7 | 模块之间通过接口通信 | 通过 `lib/` 公共函数调用来解耦 |
| 8 | 禁止复制粘贴大量重复业务逻辑 | 公共逻辑提到 `lib/` 中 |
| 9 | 不确定架构时先分析 | 不要直接重构 |
| 10 | 每完成独立功能必须 Git commit | — |
| 11 | 修改前必须阅读相关模块 | — |
| 12 | 修改完成必须运行相关测试 | 当前 27 个测试 |
